Tools

Decode a payload, open a page with the SDK, see what the SDK on a page knows, and clear a site's cookies.

Decode a payload

Paste a beacon URL, the event= value, a form body or JSON.

Open a page with the SDK

Opens the page in a new tab and adds the SDK you choose, even if the page has none.

The Personalization beacon (evergage.min.js) or the Data Cloud Web SDK (c360a.min.js), or any self-hosted copy. In that tab the page's own SDK is blocked and its Content-Security-Policy header is removed, so only this SDK runs. It stays that way while the tab stays on the same site.

Tab

The page the two sections below read and change.

SDK on this tab

Reads SalesforceInteractions and Evergage on the page.

Calls the SDK's get, is and has functions that take no arguments (for example getAnonymousId() and getConsents()). Functions that take arguments, or whose names suggest a server request, are listed but not called.

Cookies on this tab's site

Clear the SDK cookies to come back as a new anonymous visitor.

SDK cookies are _evga_… (Personalization) and _sfid_… (Data Cloud). "All" removes every cookie the page gets, including ones on a parent domain, plus the page's localStorage and sessionStorage.
